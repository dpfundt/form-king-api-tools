# Form King API Tools

## What is Form King?
Form King is the world's most modern and sophisticated Horse Racing platform. A cloud-based Software as a Service (SaaS) offering, Form King has full and extensive coverage of Australian racing, Form King is rapidly expanding into Hong Kong and internationally. Our cloud platform, web application and API are fast, user-friendly and powered with industry-leading performance ratings and benchmarked sectional data. 

## What's in this repository?
This repository contains a collection of scripts and wrappers for consumers of the Form King Modellers API, designed to lower the barrier of entry for data modellers. The code in this repository is made available for non-commercial use under a "source available" license (see LICENSE.md).

## What is an API?
An API (Application Programming Interface) is a means for computer systems to retrieve data in a predictable format, without humans needing to drive or operate that retrieval process. Almost every web page today makes use of APIs to perform its functions. Banks, news feeds, search, video playback - all of these functions are built on top of APIs that are consumed behind the scenes.

## Why would I need an API as a Horse Racing analyst?
There is only so much material that you can digest via normal browsing, and there are only so many user interfaces we can build for you. Having access to the underlying racing data gives you full control of what you see, when you see it, and how you gain insight. With huge strides being made in AI-assisted coding, even the casual racing fan can chat with AI to build against our API.
